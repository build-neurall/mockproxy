# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please do NOT open an issue. Instead, email us at hello@neurall.build.

We will:

1. Acknowledge your email within 48 hours
2. Investigate and fix the issue
3. Release a patch as soon as possible
4. Credit you in the release notes (if you want)

Please do not publicly disclose the issue until we have had a chance to fix it.

Thank you for helping keep MockProxy secure!
